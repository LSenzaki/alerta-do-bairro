# Definition of Done nos 3 Eixos

Nada é considerado pronto sem passar por esta lista.

## Computação
- [ ] Funciona de ponta a ponta no caminho principal
- [ ] Está versionado, com mensagem de commit que explica o porquê
- [ ] Outra pessoa do squad consegue rodar na máquina dela

## Sociedade
- [ ] Todo campo tem rótulo e a navegação por teclado funciona
- [ ] A linguagem é compreensível para o usuário primário (Carlos)
- [ ] Não coleta nenhum dado pessoal que não seja necessário

## Meio Ambiente
- [ ] Não reprocessa nem baixa os mesmos dados sem necessidade
- [ ] Imagens e arquivos pesados foram comprimidos (ou não existem)
- [ ] A tela não carrega recursos que ninguém usa

## Documentação
- [ ] A decisão que gerou isso está em um ADR ou no diário da aula
- [ ] O README reflete o que o produto faz hoje
